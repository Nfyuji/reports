# محرر التقارير الفنية — اشتراك شهري

## التشغيل

```bash
python app.py
```

أو `تشغيل.bat`

- دخول المستخدمين: http://127.0.0.1:5055/login
- لوحة الإدارة: http://127.0.0.1:5055/admin/login
- كلمة مرور الأدمن الافتراضية: `admin2026`

## كيف يعمل؟

1. من لوحة الإدارة تنشئ اشتراك باسم المهندس + مدة بالأشهر.
2. النظام يطلع **رقم اشتراك** تعطيه للمشترك.
3. أول ما يدخل برقمها، تننسخ له **نسخة قالب خاصة** في مجلد `users/`.
4. يعدّل ويحفظ ويحمّل تقريره فقط — ما يشوف ولا يأثر على باقي المشتركين.
5. بعد انتهاء الشهر يُوقف الدخول حتى تجدّد الاشتراك من الإدارة.

## مجلدات مهمة

- `master_templates/` — القالب الأصلي الذي يُنسخ لكل مشترك جديد
- `users/<id>/report.pptx` — نسخة كل مستخدم
- `data/app.db` — قاعدة المشتركين والاشتراكات
